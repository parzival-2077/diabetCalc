# diabetCalc — калькулятор углеводов и хлебных единиц

**diabetCalc** — простое Android-приложение для расчёта количества углеводов и хлебных единиц (ХЕ) в порции продукта. Дополнительно приложение отображает результат расчёта инсулина по одному из двух фиксированных коэффициентов.

> [!WARNING]
> Проект носит учебный и демонстрационный характер. Используемые коэффициенты инсулина (1,5 и 2 единицы на ХЕ) заданы в коде и не учитывают индивидуальные медицинские параметры. **Не используйте результат для принятия решений о дозировке инсулина.**

## Возможности

- Ввод количества углеводов на 100 г продукта.
- Ввод массы порции в граммах.
- Автоматический расчёт углеводов в порции.
- Перевод углеводов в хлебные единицы (1 ХЕ = 12 г углеводов — принятое в этом проекте значение).
- Переключение между двумя фиксированными коэффициентами для демонстрационного расчёта инсулина.
- Обновление результатов при изменении введённых данных.

## Как выполняются расчёты

### 1. Углеводы в порции

```text
Углеводы (г) = Углеводы на 100 г × Масса порции (г) / 100
```

### 2. Хлебные единицы

```text
ХЕ = Углеводы в порции / 12
```

### 3. Демонстрационный расчёт инсулина

```text
Инсулин = ХЕ × коэффициент
```

Переключатель выбирает коэффициент **1,5** (выключен) или **2** (включён). Все результаты округляются до двух знаков после запятой; в реализации промежуточные значения также округляются.

**Пример:** если продукт содержит 60 г углеводов на 100 г, а масса порции составляет 50 г, приложение рассчитает 30 г углеводов и 2,5 ХЕ. Демонстрационный результат составит 3,75 или 5 единиц в зависимости от положения переключателя.

## Технологии

- **Kotlin** — язык разработки.
- **Jetpack Compose** — декларативный пользовательский интерфейс.
- **Material 3** — компоненты интерфейса.
- **Gradle (Kotlin DSL)** — система сборки.
- **Android SDK:** `minSdk 24`, `targetSdk 34`, `compileSdk 34`.

В исходном проекте используются Android Gradle Plugin 8.3.1, Kotlin 1.9.0 и Compose BOM 2023.08.00.

## Установка и запуск

1. Склонируйте репозиторий или скачайте его ZIP-архив.
2. Откройте папку проекта в **Android Studio**.
3. Дождитесь синхронизации Gradle и установки необходимых компонентов Android SDK.
4. Выберите Android-эмулятор или подключённое устройство с Android 7.0 (API 24) или новее.
5. Запустите конфигурацию **app** кнопкой **Run**.

Для сборки APK из терминала:

**macOS / Linux:**

```bash
./gradlew assembleDebug
```

**Windows:**

```bat
gradlew.bat assembleDebug
```

После успешной сборки APK будет находиться по пути:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## Текущие ограничения

- Коэффициенты расчёта инсулина фиксированы и не настраиваются пользователем.
- Нет каталога продуктов и истории приёмов пищи.
- Расчёты выполняются на одном экране; введённые данные не сохраняются в постоянное хранилище.
- Отсутствует персонализированная медицинская логика и проверка безопасности дозировок.
